# CSharp Money Lab

Primer proyecto del programa **Bank .NET Fintech Bridge Lab**.

## Objetivo

Aprender C# esencial usando analogías con JavaScript/TypeScript y ejercicios fintech relacionados con dinero, cuentas y transacciones.

## Stack

- Ubuntu
- .NET 8.0.421
- C#
- Console App

## Analogía base

| JavaScript / Node | .NET / C# |
|---|---|
| npm init | dotnet new console |
| node index.js | dotnet run |
| console.log() | Console.WriteLine() |
| package.json | .csproj |
| node_modules/ | bin/ y obj/ |
